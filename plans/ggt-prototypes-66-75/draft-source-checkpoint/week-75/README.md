# Twists on a cylinder student prototype

Writer-stage draft, four US Letter student pages, Grades 4–5. Unpiloted. Physical rehearsal remains untested: especially removable tape with yarn feeding at fixed rim marks, seam reading, and transferring drawings to a 6-inch-circumference, 2.4-inch-high cylinder. Per pair: print the single-sided packet at 100%, scissors, tape, two contrasting yarn strands about 1.2 metres each, pencil and ruler. The cutout has no seam overlap allowance; butt the edges and bridge with tape. Prerequisites: halves and quarters, adding and canceling signed counts, and following a drawing across identified edges. A mathematician should be available for the later invariance and minimum-crossing questions.

Build with `python3 build.py --out /chosen/output` using Python 3 and a normal TeX Live installation with pdflatex, TikZ, geometry, fancyhdr, and Latin Modern. Source entrypoint: `students.tex`; output: `students.pdf`. Run `python3 check_math.py` for exact checks.

The cylinder is held still. Re-laying a strand represents a new arc; the rigid paper sleeve is never described as literally deforming through a twist. The + map adds a height-proportional full turn, fixes each boundary point modulo a full circumference, and changes the strand winding by +1. The - map is its inverse. Physical intermediate manipulation is not asserted to be a boundary-fixed isotopy of the whole cylinder. For the sliding question, the arc stays on the cylinder and its two geometric endpoints remain fixed, with extra yarn fed if needed. Upward routes form a concrete sufficient family of simple joining arcs.

The crossing question uses identical endpoints, excludes both shared endpoints, and excludes shared subarcs and tangencies. For different windings, straight lifts attain max(|a-b|-1,0); equal winding needs a small bow of one route so the arcs are distinct. The difference-of-lifts intermediate-value argument establishes the lower bound for upward arcs. Minimum-intersection results do not change when both windings increase by the same integer.

Source lineage: Diana Davis, *Billiards*, printed p.111, Problem 111 (PDF p.129), https://dianadavis.github.io/billiards-book.pdf . The source problem concerns torus shear and reassembly. It inspires the shear/unfolding representation; the boundary-fixed annulus model and the fixed-endpoint crossing calculation here are independently developed extensions, not claims from that problem.
