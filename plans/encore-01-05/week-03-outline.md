Week 3: Shuffle-machine return visits

Mathematical kernels

1. Adjacent sorting: for distinct ordered cards, an inversion is an out-of-order pair. One adjacent swap changes inversion count by exactly one; swapping adjacent inverted pairs sorts, so the minimum is the inversion count. Use small concrete scrambled rows and child-chosen hard rows; formal definition belongs to guide unless child task needs it.

2. Restricted rearrangements: a move rotates a row one place (last card to first) or reverses its entire order. For n distinct cards these produce exactly the 2n cyclic orders and their reverses for n>=3, preserving which unordered pairs are neighbors when the row is wrapped into a ring. This excludes most permutations. For n=4 reachable count8 of24, n=5 count10 of120. Kids physically compare reachable/unreachable orders; use a circular layout bridge before invariance discussion.

3. Machine square roots: can one fixed permutation run twice produce a specified target permutation? An odd cycle has a square root on the same cards (step (length+1)/2); squaring a 2k-cycle splits into two k-cycles. A square root exists iff the number of cycles of each even length is even. Thus one swap alone impossible, two disjoint swaps possible via a four-cycle; a three-cycle has a root. Offer target machines with 3,4,6 slots for concrete construction; generalized criterion is adult extension, not an undergraduate prerequisite.

Sources: elementary geometry, graph dynamics, permutations, modular arithmetic and Latin squares respectively; kernels independently derived here, not adapted problem statements. Materials

Per pair: 6 numbered cards or blocks, ordered home mat with slots at least 25 mm wide; pencil, empty arrow machines with one outgoing and one incoming arrow per slot. Use no larger deck. Cards remain face-up. Adjacent exchanges, rotations and reversals must be physically demonstrated separately. Recording a move word plus final order suffices.
