## The mathematics

A convex polygon with n labelled corners is filled by n − 3 noncrossing diagonals into n − 2 triangles; there are 1, 2, 5 and 14 fillings for n = 3 to 6. A flip swaps the diagonal of the quadrilateral two triangles form, so every filling has n − 3 neighbours. The pentagon's map is a five-cycle, so odd returns exist. The distance to the fan at v is exactly n − 3 − d_v (a lower bound plus a construction), and all fillings are connected. Flip distance between arbitrary fillings is the rotation-distance problem, whose complexity is open, so the fan case is a well-chosen exact corner. A mathematician would enjoy it; K–1 P2–P6, 2–3 P1–P7 and 4–5 P3–P7 carry it.

## App fit

Fit B, size M, as the row says. The child taps two corners to draw a diagonal (the app refuses crossings) and taps a diagonal to flip it, which enforces the one-line rule paper cannot.

- **Find every filling** of a pentagon or hexagon, or every completion of a kept diagonal (K–1 P4); the child declares done, with no slot per answer. The certificate for "all" is sorting finds by the triangle on one edge (5 + 2 + 2 + 5).
- **Flip to a target within a budget.** For a fan target, the certificate for "best" is tapping the target diagonals already present: each flip adds at most one, and the fan rule makes this exact.
- **Pentagon odd return.** "Five flips home" works here, against Proofs Tile 9: painting this map fails.

Pitfalls: for non-fan targets the missing-diagonal count is only a bound (8 ordered hexagon pairs need one more flip), so set budgets by search and offer a "best" certificate only where the bound is met. Don't ask for a predicted flip count. Keep labels fixed, so turned fillings differ. Stop at octagons.
