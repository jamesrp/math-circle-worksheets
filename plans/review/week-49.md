## The mathematics

This is Ducci's four-number game: each tower becomes the gap to the next station, all computed from one unchanged old ring. With whole-number heights every four-station run reaches zero, while three stations can cycle. The maximum never grows, an odd total has no predecessor, four moves make every height even, and scaling keeps the move count; 4–5 P5–P8 assemble these into a complete proof. A mathematician would enjoy it. P1–P4 in every band supply the experiments.

## Fix

1. **should**, K–1 p5 P6 and 2–3 p5 P5. The first printed ring, (0,1,2,4), is a longest order. It lasts 7 moves, as do its rotations and reversals; the other 16 orders last 4 (math check, problem 1). Running it answers "Which order lasts longest?". Print (0,2,1,4), which lasts 4, beside (0,1,4,2), and add it to the key.
2. **should**, 2–3 p5 P6. The printed old ring (0,1,2,4), beside an empty ring, hands over the example for "Can the tallest height stay the same for a move?": one move gives (1,1,2,4). Leave both rings blank and keep the example in the guide. I disagree with the math check's alternative, (0,1,2,3), which is also a witness.
3. **should**, all bands, pages 2 and 4, the paired mats. They are 1.0 mm apart, so the eight squares read "A B A B / D C D C" as one grid. On page 4, old B touches new C. The rule needs one untouched old ring (untested prediction). Make the stations 36 mm, centres still 52 mm apart, and move each mat 2 mm outward, for a 9 mm gap. Put the page-1 old→new arrow between the mats and update the guide's "40 mm". The math check says could; I say should, since these mats enforce the rule on every move.
4. **should**, guide page 1, "Prepare and launch" and "Flexible hour".
   - It lists "optional cubes", though the launch and the K–1 readiness note ("matches cubes") depend on them.
   - "Number cards" and the 22–25 slot's "four gap cards" are neither supplied nor described.
   - "Only then swap old/new roles" contradicts the printed labels.
   - "Forty cubes per table" covers one mat set, but two tables run two pairs (context.md).

   Make cubes standard at 40 per pair. Write "clear the old mat and move each new tower to the same letter on it". Cut the gap-card slot or describe it.
5. **should**, recording space.
   - K–1 p4 P5 and older p4 P4 stop "when the whole ring repeats", but the cubes show only two rings and (1,0,1) recurs three moves later. Add about six A-B-C record rows under the three-station mats.
   - 2–3 and 4–5 p3 P3: add a four-box row under each target for the old ring.
   - 4–5 p5 P5 offers two blank rings for a check of 16 patterns. Use rows of letter boxes, or the 16 cards the guide mentions.
6. **should**, all bands, page 2, under Problem 2. "Use these big mats for all four-station starts." says what a blank space is for (neg.md). "An all-zero start takes 0 moves." is needed from Problem 1 on. Delete the first sentence and move the second into the page-1 rules. That also settles K–1 P3, whose wording admits (0,0,0,0) while the key excludes it (math check, problem 3).
7. could, page 1 caption: "All four gaps use the old ring." repeats the rule.
8. could, 2–3 P5: "Two rings count as different here only when…" defines a count the question never asks for.
9. could, 4–5 P6: its first start is the page-1 example. Use (2,5,1,0) and (4,10,2,0), which take 6 moves each.
10. could, the theme has three names: "Four-tower differences", "Four tower differences" and "Four towers and differences".
11. could, bonus: page 1 says "Grades 2-5" and pages 2–3 say "Grades 4-5". In P3, change "within five rounds" to "by round 5" (math check, problem 4).

## App fit

A, size S, as in themes.md. The app would animate the rule, so running it is predict-an-outcome, which children liked less. Solves should be reverse or design goals:

- Predecessors (2–3 P3; bonus P1): tap heights on an old ring, with live gaps on the arrows, to make the target. "Can't" needs a certificate: an odd total, or three zero gaps.
- Grow a run backward from (c,c,c,c), one predecessor at a time under a height cap, toward 7 moves (K–1 P3–P4, P2).
- A three-station ring that never reaches zero (P4).
- Sorting the 16 E/O rings by how many moves they take to reach EEEE (4–5 P5).

Pitfalls:
- A free Run button invites fishing: 16 of the 625 starts with heights 0–4 last 7 moves.
- Don't show a slot per answer in "find every predecessor".
- Only exhaustive search shows that 7 is best, so don't ask a child to certify it.

**Decision, October 10, 2026.** Port, in Wave 7 (sets and numbers), with reverse goals only: build a predecessor ring (or show none exists by odd total or three zero gaps), grow a run backward under a height cap, and find a three-station ring that never reaches zero. No free Run button. Tracked in the app's [decisions.md](https://github.com/jamesrp/small-math-adventure/blob/main/docs/plan/decisions.md).
