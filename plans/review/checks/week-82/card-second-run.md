## The mathematics

A complete match needs equal size, and every line here has the same size; keeping order needs equal order type. A star before an endless line is absorbed (star → 1, n → n + 1: 1 + ω = ω). A star after every kid is a last kid, which the plain line lacks, so ω + 1 ≠ ω (P2). Two endless blocks contain B1, with infinitely many kids before it, so they match a row of pairs only if order may change (P3: ω + ω ≠ ω). P4's 16 lines of up to two rows and two stars fall into six order types, fixed by the number of rows and the stars after the last row (math.md). A mathematician would enjoy it: order-dependent addition, reached by moving one star.

There is no real on-screen solve. The finite part is thin permutations that Cup swaps already has. The substance is a rule for every kid of an endless line, which a screen could check only by continuing the few lines a child draws (doing the generalizing for the child) or by panning, which never ends. Each certificate is one obvious tap (the end star, the second row's first kid), so it can't fail. Sorting P4's 16 lines is solved every time by counting rows and trailing stars, so it repeats after a puzzle or two, as Weeks 73 and 79 did. The cards, panels and argument stay on paper. decisions.md's row should say "Endless class lines", not "Endless queues".
