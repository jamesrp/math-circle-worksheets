## The mathematics

A yes-or-no answer at best halves what is left, so k answers separate at most 2^k things: three questions find one of eight blocks and two never can, and 1 to 20 needs five (K–1 P1–P4, 2–3 P1–P3, 4–5 P1). In the code game a score is n minus the Hamming distance, and it has n + 1 values, so counting answers proves almost nothing. All red, then one turned counter at a time, finds any n-counter secret in n tests, and the true minimum is 2, 3 and 4 for 2, 3 and 4 counters: turning one counter moves any score by exactly 1, so the rows next to the first test get too few scores (4–5 P7–P9). Ending on a full score costs one more test (2–3 P9, 4–5 P10). A mathematician would enjoy it: this is coin weighing at a child's scale, and the 4–5 chain reaches a lower bound where counting fails.

1. **must**, guide p. 7, 2–3 P11: "Testing every place separately without the count takes 5." Testing every place without the all-red test works in 4: YRRR, RYRR, RRYR, RRRY give all 16 secrets different scores (both reviews and the math check). YRR, RYR, RRY does the same for three counters, so a child who used it in P8 will bring it here, and the line tells the adult it needs a fifth test. P11 asks for the worst case of the child's own method. Replace with the math check's line: "All red and then each of the four places takes 5. Using the count, or leaving out the all-red test (YRRR, RYRR, RRYR, RRRY: the higher scores are the yellow places; all 3s mean RRRR, all 1s mean YYYY), takes 4." Add YRR, RYR, RRY to the P8 answer. The math check lists this among guide slips; both reviews rate it a must, as for Weeks 25, 31, 39 and 43, because an adult would correct a right method.

## App fit

Fit A, confirmed. Signal Lanterns already plays fixed transcripts, which cover K–1 P7, 2–3 P7 and 4–5 P3. Add an adaptive mode: the child sets the lanterns and taps Test; the app scores adversarially, keeping as many secrets consistent as it can, with a budget of n tests. The solve is naming the secret once only one fits; if two still fit, the app shows the other. That pair is the certificate for "can't": with n − 1 tests (n ≤ 4) the adversary always keeps two, and a proof puzzle can ask for two secrets a transcript cannot separate. A design group fixes the tests in advance (2–3 P8, 4–5 P4, P6): the app checks all 2^n secrets and shows a colliding pair; the hardest is four tests for five lanterns (guide p. 9). A full-score group gives n + 1 tests (2–3 P9, 4–5 P10), and yes-or-no questions against the same keeper cover 8 blocks in 3 and 1 to 20 in 5. Pitfalls: never show which places match or a live count of secrets left, which does the reasoning; a random keeper turns the budget into luck; no predict-the-score quizzes. "No secret fits" games can become "which score is wrong"; 4–5 P7 suits a playground. The block game is close to the balance; at most a short group.
