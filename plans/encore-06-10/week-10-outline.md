Week 10: Bridges and one-stroke drawings - return visits

Mathematical kernels

1. Directed streets: a walk must follow each arrow and use each street once. A finite directed graph with nonisolated vertices in one connected underlying component has a closed Euler walk iff indegree=outdegree at every vertex; an open Euler walk iff one vertex has out-in=1, one has in-out=1, and all others balance. For balanced connected graphs the edge-bearing part is strongly connected; splice directed cycles. Ignoring arrows can give the wrong answer. Children orient craft-stick streets and move an arrowed token, with one counter removed per traversed edge. Multiple streets and loops can exist if explicitly drawn; simple initial towns need no loops.

2. Route choices can strand a walker even in a town known to have an Euler walk. With two odd vertices, start at an odd vertex; while unused edges remain, avoid a bridge of the remaining graph (including the current token and destination vertices), unless it is the only available edge. Fleury's rule preserves completion in the finite undirected connected setting. A triangle A-B-C-A with a tail A-D has an Euler walk fromAtoD: takingADfirst strands the triangle; takingABorAC first succeeds. A richer example can have two cycles joined by a bridge. This concerns safe local choices and testing consequences, not base classification or adding/repeating bridges. Prefer tangible failed routes and counter resets before articulating the rule; the safe-choice test is whether the new token location can still reach EVERY remaining edge; an isolated token destination fails this test. This test need not be printed as a procedure.

3. Password windows connect directed routes with overlapping messages. A binary length3password occurs whenever three consecutive button presses match it. Return-visit scope and format

Create one shared student PDF `draft/return-visit.pdf`, with three distinct numbered investigations (normally one page each, more if space is needed).
