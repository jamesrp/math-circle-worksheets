{\LARGE\bfseries A game to take home}\par\medskip
At math circle we hunted for \emph{allowed threes} among nine tiles: the shapes all the same or all
different, and the fills all the same or all different. Your SET deck uses the same rule with four
features on every card: how many shapes, colour, shape and fill. Three cards where every feature is all
the same or all different are called a \emph{set}.\par\medskip
\textbf{Start small and grow:}
\begin{enumerate}[leftmargin=1.5em,itemsep=2pt,topsep=2pt]
\item \textbf{Nine cards.} Take the cards that show exactly one red shape. They work just like our tiles. Find all the sets.
\item \textbf{Twenty-seven cards.} Take every card that shows exactly one shape, in any colour. Lay out nine and hunt for sets together.
\item \textbf{The whole deck.} Deal twelve cards face up. Find a set, say ``Set!'', show it and keep it, then deal three more. If nobody can find one, deal three extra.
\end{enumerate}\par\medskip
\textbf{A question to keep:} with the nine cards, the most you can pick with no set is 4. What about the 27 cards?\par
