Each one went through the full workflow, with every stage run by a fresh agent: the writer stage, an adversarial review (`review.md`), an independent math check that re-solved every printed board with its own code (`review-math.md`), and a revision that addressed both reviews.

What the reviews changed, in brief:

- **Towers from either end.** K–1 Problem 1 can now record a tie. "Play as well as they can" is defined where a page asks "by how many". The slot-number record has a worked example. Rows that invited a false rule ("always take the shorter end", "take the taller end") were replaced with checked rows. Problem 9 in grades 2–3 no longer has its answer printed in Problem 7. The red/blue strips begin on a later page, so children can be given them as a second set after playing on plain strips.
- **Breaking and drawing games** (outline: "Games decided before they start"). The header no longer announces the discovery. The token rule now says each end of a line needs its own token, so a loop needs two. Lines may not cross themselves or another line; both gaps had let game lengths vary and changed winners. Grades 2–3 now record line counts, and K–1 players swap who goes first. In grades 4–5 Problem 10, a line through a cross counts as two pieces.
- **Poisoned cookie.** "A position where the player whose turn it is cannot make sure to win" replaces "an L position", which a child could read as an L shape. The strategy-stealing question now asks which step of the argument breaks. Square boards are "bigger than one cookie". The make-a-board problems start from a full grid, so the answers are boards that can occur in a game. Full-size boards that share a page sit far enough apart for the bite card.
- **Who beat whom.** Every K–1 problem now says which board to use, and the big board's lanes hold the 10 cm arrow cards. Grades 2–3 Problem 3 has a recording diagram, the line-up answer gaps are wider, and grades 4–5 Problem 7 has larger diagrams and six blank pentagons for four possible answers, so the number of blanks no longer hints at the answer.
- **Hidden armies.** K–1 Problems 2 and 4 now ask "Is there a plan…?", since with 4 or 5 cubes no plan is unbeatable. The claim "you can beat any plan" is limited to plans with 6 or more cubes, because 1-1-1 cannot be beaten with 3. Grades 2–3 Problem 7 allows a different number of cubes, not fewer, since beating 1-1-1 takes 4. "Circle the plan that won" adds "if one did", because many games tie.
- **Patterns you cannot avoid.** The K–1 pages are landscape, so the strips print at the 25 mm size of the counters and combs. The K–1 game checks with the combs after every turn, so a missed three does not penalize the wrong player. Questions no longer say "in order", which led children into dead ends, and ask why no colouring can go further. The third colour is named (green), the 4–5 recording strips have different lengths so their count gives nothing away, and the repeated six-dot question became Sim's "would you rather go first or second?".
- **Pancake flips.** Grades 4–5 Problem 3 now uses a stack with four breaks (3 5 2 1 4), so Problem 5's hunt for the worst stack of five is not already answered. K–1 sorts the worst stacks of four instead of proving that a stack cannot be sorted faster, and its one-flip problem has three blanks for three answers. Grades 2–3 sorts six-pancake stacks before asking for a general method. Every band gets a worked dark-side flip.
- **Train-yard sorting.** The ✓/✗ grids were reordered, because the trains that work had all sat in one column. A printed track mat was added; none existed. Grades 4–5 make extra paper cars for longer trains and treat the siding as long enough, so the two-siding answer no longer depends on the mat's five-car wall.
- **Counting-out circles.** Every band's rule now says to keep going past spot 1 without starting over, since a child who restarts each lap finds 1 last every time. The 16-spot and 32-spot mats are printed; the 32-spot loop spans two Letter pages because no counter-sized ring of 32 fits on one. K–1 guesses before playing instead of copying earlier answers, and its "how many people" question became "Which circles left number 3 standing?". Grades 2–3 explain why 16 and 32 leave number 1 before predicting 50 and 100. The every-third rule no longer says "3 sits down", which fails in circles of 1 and 2. In grades 4–5 the binary example is a circle of 12 instead of 13, because 13 also fitted the wrong rule "reverse the digits", and the check circles are named (14 and 21) so they test the wrap-around.
- **Untangling networks.** The rules now say no more than two links may cross at one place, since several links through one point make the fewest crossings for six dots smaller than 3, and the region rule asks only about networks in one piece. Houses and wells are drawn as pictures and come early in K–1, where the impossible problem now asks for as few crossings as you can rather than hinting that it cannot be done. The portal boards have numbered sides and Week 41's seam marks. Grades 2–3 draw on the portal board before explaining why five dots each joined to every other cannot be untangled, and in grades 4–5 the portal board comes before the six-dot crossing proof. The link game has printed boards.
- **Hex.** K–1's impossible tasks became questions ("Can you…?"). Grades 2–3 play out the Blue-to-move positions on full-size boards, and their blocking problem asks for the fewest blue counters and why fewer will not work. Grades 4–5 colour their own boards to test the boundary path, whose rule now counts the coloured edges as red and blue; meet a concrete position before strategy stealing (does an extra red counter ever hurt Red?); and Maya's claim now says "playing by the rules on page 1", since real-world Hex adds a swap rule. The largest board has its own landscape page.
- **Graceful labels.** The shared rule now names the cards under each network and says the link numbers must be 1 up to the number of links, so it works for every network, and a worked example shows a labelling that works and one that does not. K–1 has a worked picture from towers to written numbers and counts the empty dot as 0. Problems that include networks with no labelling let children cross them out or explain why, and in grades 4–5 the loop proof comes before the long loops it explains.

## Rebuilding

Each `src/` folder rebuilds its three PDFs into the draft folder with Python 3 and pdfLaTeX. The commands are `python3 gen.py` (towers), `sh build.sh` (breaking and drawing games; who beat whom, which writes into `src/`) and `python3 build.py` (poisoned cookie), each run inside `src/`. Each build also runs that draft's answer checker. On October 24 all four rebuilt from a clean copy, with text identical to the committed PDFs.

For ranks 5–8, also run inside `src/`: `python3 build.py` then `python3 check_answers.py` (hidden armies); `sh build.sh`, which runs `verify.py` first (patterns); `python3 gen.py` then `python3 check.py` (pancake flips); `python3 build.py` then `python3 verify.py` (train-yard sorting, which also builds `track-mat.pdf`). Each writes its PDFs into the draft folder. On October 25 all four rebuilt from a clean copy with text identical to the committed PDFs, and every checker passed.

For ranks 9–12, run inside `src/`: `sh build.sh` (counting-out circles, which re-checks every answer; untangling networks, whose `nets.py` checks the pictures, the portal drawings and the link-game boards and needs the Python package `networkx`; graceful labels, which writes `answers-check.txt` and `geom-check.txt`) and `python3 build.py` then `python3 check_hex.py` and `python3 check_puzzles.py` (Hex). Each writes its PDFs into the draft folder. On October 25 all four rebuilt from a clean copy with text identical to the committed PDFs, and every checker passed.
