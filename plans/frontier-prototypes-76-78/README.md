## Workflow

The shared workflow and context are unchanged. Each outline is processed by `worksheet-workflow/make_prompts.py`. A documented run-local scope addendum replaces the default three-band outputs by one shared prototype `students.pdf`; all student-page standards and fresh writer, adversarial critic, independent mathematical checker and reviser stages remain in force. Each implementing stage receives a separate checkout/worktree and exclusive output ownership. The adult guide is a separate, untested workflow stage, followed by an independent check. It opens with precise theorems, hypotheses, limits and a map to the student investigations before individual answers.

About four substantial student pages per theme and a compact matched adult guide are planned. Scope may change when review reveals a better investigation. Every final page will be rendered and inspected; every portable source ZIP will be extracted and rebuilt without repository inputs. Claims about mathematical proof, digital verification, physical rehearsal and classroom piloting are recorded separately.

## Sources and preservation

The owned source notes distinguish established source mathematics from the packet authors’ examples, finite models, proofs and pedagogical choices. No whole downloaded books or papers, borrowed artwork, raw research dumps, workflow prompts containing borrowed style examples, private classroom records, credentials, build caches or render intermediates are included in the deliverables. The existing `REPUBLISHING.md` caveat remains unchanged.

Research/outlines and editable-source milestones are checkpointed before long review stages. A local commit is not treated as durable publication: the parent verifies the public repository ref after each authorized external write.
