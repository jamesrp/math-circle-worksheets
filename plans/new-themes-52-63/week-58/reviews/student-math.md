## Assumptions, limits and exact versus experimental claims

Each observer uses their own unchanged value scale on every bundle. These are nonnegative additive goods; zero-valued items or observers remain participants. Complete allocation means every item/resource part belongs to exactly one person. Ties pass. Comparing A's score for A's tray with B's score for B's tray is not a fairness test; none of the printed tasks requires that comparison.

For observer i, envy-freeness gives `value(own) >= value(tray j)` for every j. Add all n comparisons to get `n * value(own) >= total`: proportionality follows. For n=2, `value(own) >= total/2` gives `value(own) >= total - value(own) = value(other)`. Problem 6 supplies a complete three-person counterexample to the converse. Completeness and additivity are essential to these arguments. For example, if two people each receive a value-1 item while an additional commonly valued item of value 10 remains unallocated, their assigned bundles are envy-free but neither is proportional relative to all the available goods. Do not use discarding to solve Problem 5.

Exact cut-and-choose requires the cutter's equality and the chooser's own weakly preferred choice; additivity relates each comparison to half the whole. The cutter gets an indifferent half and the chooser a maximum of two whose sum is their total. Existence of the cutter's exact interval cut needs a divisible/nonatomic valuation with a continuous cumulative value (the printed constant-density paper panels satisfy this ideal model). A physically splittable object alone is insufficient if the entire subjective value is concentrated at one point. Page 4 conditions its claim on the exact equal-value cut and therefore does not falsely assert existence for all arbitrary tastes. Millimetre/scissors error is an approximation, not a proof of exact equality. Source/adult notes already disclose this distinction.

There is **no three-person moving-knife, discrete proportional algorithm or Selfridge–Conway procedure in the actual student packet/materials**. The inspected source contains such background, but this packet establishes the difference between two fairness conditions, not a full three-person algorithm or impossibility for divisible cake. Research's warning about naively cutting three equal pieces and letting two others choose is correct: a cutter valuing X,Y,Z as (1,1,1), with both choosers valuing them (3,0,0), can give the first chooser X while the second gets a zero-valued panel and envies X. The current printed cyclic counterexample does not itself implement that naive procedure; keep this boundary explicit in any future guide.

The fresh finite checks supplement these explanations: **4,096** two-person nonnegative value profiles on three goods, **32,768** complete allocations, including all-zero profiles and empty trays; **169** two-bundle and **2,197** three-bundle observer rows; and **308** legal choices after exact halving for two-panel densities 0–3, including ties and zero density. Universal claims are justified by the algebra above, not by these finite counts alone.

## Located corrections and smallest fixes

1. **Grades 2–5, student p. 5, Problem 5; material p. 1: paper R3 can be read as an extra good.** Exact text: “For a second trial, you may cut the paper copy of R3 into pieces; R1 and R2 must stay whole.” The material page contains both the reusable R3 and another cuttable R3. If both remain, total value is 4 rather than 3: U can receive R1,R2 and V the original R3 plus the paper R3, giving 2 each without cutting. That destroys the intended indivisibility contrast. **Minimum fix:** “Replace R3 with its paper copy; you may cut that copy.” Adult preparation must remove the original R3 in that trial. Keep the whole-paper value 1/equal-area convention.

2. **Grades 2–5, student p. 3, Problem 3, score table; source README prerequisites: exact alternative scores require thirds.** Exact request: “Find where each person should cut and how each person values both pieces.” The four score rows require 2/3 and 10/3, whereas the README says exact fractional scoring is not a younger entry prerequisite. The numbers are correct; the prerequisite statement and required record are inconsistent. **Minimum fix:** make the main record the child-selected cut and chooser's piece and reserve exact alternative-observer scores for fraction-ready work, or explicitly gate the full numerical task on thirds while retaining the concrete cut/choice route. Do not remove differing valuations, print the cut answer, or replace the investigation with equal-count sharing. This confirms `review.md` issue 1; it is an operational mismatch, not a claim that these unpiloted children cannot learn thirds.

3. **Grades 2–5, student p. 2 bottom table; Grades 3–5, student p. 6 bottom table: bind the record to an allocation.** Page 2 has six allocation slots but one table headed “Their own tray / The other tray”; no slot is identified. Page 6 has the initial check and repaired state but one table with two identical “Other tray” headers. This does not change any computed answer or prescribe sequential updating; it leaves the recoverable record unclear. **Minimum fix:** identify one saved catalog allocation on page 2, and label page 6 as the initial-state check with A/B/C tray-owner columns; alternatively remove these supplementary tables. Retain one unchanged observer and one unchanged allocation for each full check. This confirms `review.md` issue 4.

4. **Materials pp. 1–3 and source preparation notes: distinguish necessary kit pages from stock and upper copies.** Page 1 supplies R4,B3,B4,G1–G4, seven reusable goods unused by any printed task; the green preference rows have no task use. No extra student problem is needed to justify them. **Minimum fix:** omit unused cutouts/rows from the current worksheet kit (or explicitly identify them as optional spare inventory), and give an exact page/copy recipe. For the current PDF, five pair kits require one copy each of pp. 1,2,3,6–10 per pair; the extra upper kit needs one copy of pp. 4–5, not five. This is **42 material sheets** if all ten strips per pair are stocked, with 50 finished strips across five pairs. Ten strips per pair are authorized consumable stock, not ten required trials; a first-route print subset can be described separately. Trays/rulers are separate. This confirms the actionable preparation part of `review.md` issue 3 and does not demand extra band coverage or page padding.
