## Prioritized findings

1. **Week 1 encore, grades 4–5, page 4, Problem 4: the flat tiling to cube-pile bridge is incomplete.** Children are told to shade their filling like pictures A and B and build the cube pile it shows. A is an empty box corner (0 cubes); B is a full 2×2×2 box (8 cubes). These two extremes do not show how a new cube changes the visible faces and rhombi in an intermediate tiling, and the concave/convex reading is itself unfamiliar. The mathematical task becomes inaccessible if the adult has to interpret every tiling. **Minimal fix:** introduce one cube placed in the empty corner, next to its matching shaded rhombi, with the corresponding faces visibly matched. Use the same viewpoint as A/B. Keep the general cube-count and flip discoveries open. The guide already has “Start from A, add one cube in the corner, and draw the new picture” as its third hint; this is better treated as essential introduction at this transition. A dedicated live demonstration can supply the bridge, but the normal whole-group placement-game launch does not: it only teaches legal rhombus placement. High confidence in the representation gap; no claim that children have been observed failing here.

2. **Week 6, grades 4–5, page 1: rules precede the wrong activity.** The first, longest paragraph explains the keeper, breaker, red/yellow counters, green-triangle scoring, folder and referee. Problem 1 instead asks children to guess a number from 1–16 with yes/no questions. A child reasonably tries to connect the counters and scoring to this number game, or has to remember unused machinery until page 2. **Minimal fix:** move the existing code-game paragraph to page 2 immediately before Problem 2; keep page 1 focused on the number game. A normal teacher demonstration does not justify putting unrelated rules before first action. No extra printable or worked example is needed to fix this sequencing issue.

## Demonstration-dependent watchpoints, not required redesigns

- **Week 3, all bands, page 1:** demonstrate one complete turn, including moving every block down its arrow and then returning the entire output row vertically. The page states both steps clearly, and the physical mat preserves positions. This is an ordinary launch requirement, not a missing independent investigation. The return-visit packet page 3 has an especially good repeated-machine example if a future printed reminder is wanted.
- **Week 6 code-game entry:** grades 2–3 page 3, grades 4–5 page 2 with rules currently on page 1, and K–1 page 4 need one open scoring trial before the folder hides the rows. The aligned physical mats make this demonstrable. Unlike the encore cube conversion, all scoring rules are already stated and children then make their own tests.
- **Week 8, grades 4–5, page 4:** splitting piles into distinct 1, 2, 4, 8, ... stacks is terse. Check during launch that children understand “no two stacks in one pile the same size.” A small physical split can help if needed. Do not remove the rich Nim investigation or automatically print the rule they are meant to discover.
- **Week 9 cut/fold transitions:** K–1 page 8, grades 2–3 page 7, grades 4–5 page 4. Drawing, cutting selected tiles, folding and viewing through paper form an unfamiliar physical procedure. A live fold demonstration can suffice; the exact handling and visibility must be rehearsed. This audit did not physically rehearse them, so it does not certify those transitions as classroom-ready.
- **Week 11, all bands, page 1:** the printed example explains the letter record rather than chip motion. The guide explicitly supplies a live chip-sharing launch, moving only the chips from the selected circle. With that ordinary demonstration the legal action is simple and the word is one recoverable record. K–1 needs adult reading and likely scribing. I do not classify the absence of another printed worked move as a blocker.

## Representative positive examples

- **Week 1 base, K–1 and grades 2–3, page 1:** meaningful physical fitting tasks, immediately visible goals, and ample working outlines. Extra examples would use space without clarifying a difficult convention.
- **Week 1 base, grades 4–5, pages 1–3:** rhombus recording symbol, local flip and ribbon are introduced where each becomes useful; the graph question follows actual tilings.
- **Week 3 return visit, page 3:** input values differ from position labels, and the output is visibly returned to the same input positions before the second pass. This directly resolves a common repeated-operation ambiguity.
- **Week 4 return visit, page 1:** both counters move before checking, with explicit intermediate hops and one ordered pair afterward. The example preserves simultaneous state correctly.
- **Week 5 K–1, page 1, and return visit, page 1:** the eye-level tower drawing grounds visibility; the separate return visit explicitly maps a physical tower to its numeral record.
- **Week 7 return visit, pages 1–3:** PASS, LAST-card and adjacent-pair changes are each shown through a short physical transition; the added rule stays visible on the table.
- **Week 10 return visit, pages 6–7:** the sliding window is shown on a short row, then the circular join is demonstrated separately. The examples teach the operation without solving the requested three-button optimization.
- **Week 12 grades 2–3, page 2, and grades 4–5, page 2:** the pairing/code/path and tree-walk/code/path bridges have matching visual labels. The code is not introduced as unexplained terminology.
