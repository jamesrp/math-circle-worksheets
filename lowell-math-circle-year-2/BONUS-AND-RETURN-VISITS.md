# Bonus investigations and return visits: Weeks 1–51

Local delivery index, October 4, 2026. **Complete: 51 of 51 themes released, with 153 distinct new investigations.** Each week offers three mathematical directions; numbered problems, contrasting examples, grade-band entries and possible visits are counted separately. These companions extend the existing theme library. Choose one investigation, allow concrete exploration, and return when children want to continue; completing every page is not a session goal.

**All new material is unpiloted. Physical fit, materials and procedures have not been rehearsed.** Grade bands are approximate; use the adult guide's reading, arithmetic and reasoning prerequisites. Supported oral or concrete K–1 entries are identified where available. A week with only 2–5 or 4–5 bonus choices can use its existing K–1 base activities alongside them. Print selected student pages on US Letter at 100% / Actual Size; adult guides are separate.

Current copies and portable sources are local. No Drive upload or publication was performed for this expansion; existing Drive copies remain older and omit these additions.
