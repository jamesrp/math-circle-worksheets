# Week 24 guide before the October 23, 2026 critic follow-up

The adult guide of the card-fix release, replaced the same day. The current guide lists 58 cards and has the spares written in soft pencil. Nothing else changed; the student packets and bonus are not duplicated here. The current copies are in [../](../).
