## Routes and relationships

- **Week 52:** Changing shapes → local braces → row/column links → minimum bracing and count limits.
- **Week 53:** Buy a connected network → remove loops → improve by exchange → certify minimum cost and examine ties.
- **Week 54:** Small strip catalogs → odd/distinct matching and inverse → join-order independence; a separate row/column investigation.
- **Week 55:** Distinct sums → the smallest possible sumset → explain the bound and recover equal spacing from equality.
- **Week 56:** Assembled incidences and corner fans → total angular gap → surface redrawings and Euler's formula.
- **Week 57:** Compare area, inside dots and boundary dots → lattice-polygon rule → joining, subdivision and holes.
- **Week 58:** Whole-card division → divisible strips and cut-and-choose → indivisibility → proportionality versus envy-freeness.
- **Week 59:** Measure while turning between parallel supports → noncircular constant width → explain the support geometry.
- **Week 60:** Irreversible take/pass play → complete equally weighted cases → continuation values, changing thresholds and optimality.
- **Week 61:** Surface routes and corners → great circles and shortest arcs → spherical triangles, lunes and excess area.
- **Week 62:** Minimum slots → odd cycles → first-fit order and repair → counts with named slots.
- **Week 63:** Card-to-home assignments → overlapping forbidden events → complete derangement counts and reversible recurrence cases.
