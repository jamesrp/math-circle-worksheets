# Week 24 encore student source
Run `python3 build.py [output-directory]` with pdflatex on PATH, or set `PDFLATEX=/path/to/pdflatex`. Output is `bonus.pdf`; intermediates go under the chosen output directory (default `..`). Standard LaTeX packages: geometry, TikZ, array, fancyhdr, lmodern. No project files or absolute paths are required.
