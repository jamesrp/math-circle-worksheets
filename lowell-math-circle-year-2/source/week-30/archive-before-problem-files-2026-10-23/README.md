# Archived base source: before the problem-file conversion, October 23, 2026

`make_packets.py` and `draw.py` are the old student builder. They wrote and compiled the three band LaTeX files. The student pages are now stored as problem files one directory above (`week.toml`, `figures.py`, `problems/`); `editable/student-src/regenerate.py` writes the same LaTeX from them, byte for byte, and compiles it.

`two-pan-weight-kits-week30-editable-source.zip` is the complete portable package it replaced: the October 4 fresh-review release. None of these files is current. Bonus companions are separate.
