# Week 18 shared encore student pages

Build with `bash build.sh [output-directory]`. Requires a TeX distribution with TikZ. If `pdflatex` is not on PATH, use `PDFLATEX=/path/to/pdflatex bash build.sh`. The source is portable and defaults to `../bonus.pdf`; no project files are required. A supplied output directory is relative to this source directory unless absolute; PDF and TeX intermediates go there.

Print on US Letter at 100%. The large strips have 25 mm-square cells; the large array has 25 mm-square cells. Smaller diagrams are pencil records. Counter fit and hole recognition have not been physically rehearsed. This revised student packet is unpiloted.
