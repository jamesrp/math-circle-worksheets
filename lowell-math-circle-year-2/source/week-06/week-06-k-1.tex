\PageTitle{K--1}{Which secrets are still possible?}\NameLine
\RuleBox{Two colors: R and B. Repeats allowed. A test earns one point for each color in the correct position. You hear \textbf{only the total}, not which positions match.}\Task{1. Learn the checker job.}{Use two counters. First leave the secret visible. Try some tests. Check one place at a time, then say only the total. Now hide the secret and play.}
\Task{2. Make all four secrets.}{Build these four rows. Use different shapes as well as colors if you like.}\begin{center}\fontsize{24}{30}\selectfont\Code{RR}\qquad\Code{RB}\qquad\Code{BR}\qquad\Code{BB}\end{center}
\Task{3. One answer rules some out.}{The test \Code{RR} scores \textbf{1}. Cover every secret that cannot fit. How many remain?}
\WriteBox{Draw or point to the secrets that remain.}{1.35in}
\Task{4. Choose a useful next test.}{What test could tell the remaining secrets apart? Try it with both possible secrets.}

Put possible secrets below each answer.}\begin{center}\begin{tikzpicture}[x=1in,y=1in]\node[draw]at(2,1.4){test RR};\foreach \x/\s in {0/0,2/1,4/2}{\draw[->](2,1.15)--(\x,.65);\node[draw,minimum width=.65in]at(\x,.4){score \s};\draw(\x-.65,-.8)rectangle(\x+.65,0);}\end{tikzpicture}\end{center}
\Task{6. Finish every branch.}{If two secrets remain, choose a test that separates them. If only one remains, you can name it without another test.}
\WriteBox{Could one test always tell the secret? Show a troublesome answer.}{1.1in}
\textbf{Play again:} Exchange maker and finder jobs. Can you follow your tree for every secret? An adult can do the writing; you supply the reasons.
