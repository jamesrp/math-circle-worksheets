# Week 40 revised student source

Revised and unpiloted. Student pages only. K–1 use is conditional on reliably following a whole arc through its overpasses, which Problem 1 (count the figure-eight's whole arcs; four) shows. If that readiness check fails, do not proceed with the coloring tasks for that child. No physical cord models have been pretested here. Adult preparation and physical pretesting of the exact intended models remain required before teaching. Mathematical diagram verification is not a physical-model check. Cords stay on the table and children never cut them.

The original trefoil is generated from the standard spatial parameterization (sin t + 2 sin 2t, cos t - 2 cos 2t, -sin 3t), with actual projected crossings numerically located on 1,200 segments. Depth determines which branch is under. The three arcs are traced between underpasses. `knot_geometry.py` independently enumerates the coloring constraints: nine total, six nonconstant. The 148 mm-wide target diagram has approximately 70.27 mm between crossings. `geometry-check.json` records the data. The plain loop also has width 148 mm. Small isolated crossing examples are representation keys rather than target knot diagrams.

Run `bash build.sh` with Python 3, pdfLaTeX, TikZ, Latin Modern, AMS fonts, and Poppler installed. Since October 23, 2026 the `.tex` files are generated from the problem files by `regenerate.py` (see the week's README); the trefoil geometry is repeated in the problem files' `figures.py`. The script uses the caller's TeX environment and runs TeX twice for page anchors. PDFs are produced in `../` and rendered pages/build records in `../qa/`.

Since v3 (October 23, 2026) the K–1 packet is five pages, grades 2–3 four and grades 4–5 six. The figure-eight in Problem 1 (70 mm) and grades 4–5 Problem 7 (148 mm) is the plane curve (cos t − 1.5 cos 3t + 0.5 sin 2t, sin t + 0.5 sin 2t − 1.5 sin 3t) with its four crossings taken alternately over and under; `figures.py` asserts four crossings and `../review/verify_card_shoulds_2026_10_23.py` reads 3 three-colorings and 25 five-colorings back from the PDFs, with the grades 4–5 curl and slide. The coloring channel is widened to 2.4 mm, with 3.2 mm outer strokes and enlarged underpass gaps. Actual color strokes plus letter labels are used in the representation keys and missing-color tasks. The target trefoil remains uncolored; 1, 2, 3 name its arcs. The crossing-free loop is explicitly one arc. Twelve recording places avoid revealing the number of valid target colorings.

The added K–1 local strand task has six numbered endpoint assignments (L,P,S,Q; the dot called R before v3 is S). Cases 1,3,5,6 work and 2,4 do not. In case 2 the horizontal endpoint colors differ; in case 4 the endpoints of the continuous overpassing bend differ. All successful cases have a unique middle horizontal color. These are code-verified local facts; the full knot-coloring invariance remains a supplied theorem in grades 4–5. Adults must still assemble and physically check the plain loop, trefoil and two complicated unknots. The widened print/marker combination has not been physically tested.
