# Week 23 shared encore student pages

Build with `bash build.sh [output-directory]`; set `PDFLATEX=/path/to/pdflatex` if needed. Requires TikZ. PDF and TeX intermediates default to `..`. No other project files are required.

Print US Letter at 100%. Printed networks are pencil records. For handling 30 mm cards, supply the separate reusable 24×30 cm four-lane mat and two-endpoint comparator strips. Move all cards to the next bar together. Sorted-pair trays preserve merging inputs. Manual swaps, changing bars after seeing an input or comparing tags change the task. These physical procedures are untested; this revised student packet is unpiloted.
