# Week 90 — Sliding number arrays

Owned editable source for the current unpiloted release. Shared Grades 2–5 menu; no K–1 packet is claimed. Children need to compare small labels, preserve masks and a single active hole, and reset from an unchanged card. Adult reading/recording is appropriate; adults should not choose every move. Whole-slide choices, target construction, preimages, reversal and local proofs are separate return routes.

- `student/students.tex`: eight pages, nine consecutive student investigations with complete forward, multiple-missing-corner and reverse convention examples.
- `student/materials.tex`: eleven pages of 30 mm working inserts, 26 mm pieces, all A/D/B catalog cards and blank group cards.
- `guide/facilitator.tex`: nine-page theorem-first assumptions and limits, complete catalogs and keyed solutions, route-specific preparation and proof/evidence distinction.
- `check_math.py`: independent standard-library enumeration of all supplied starts, legal corner sequences, complete results and reversals.
- `reference-pdfs/`: exact delivered PDFs.

Run `python3 build.py --out rebuilt`. Requires Python 3 and pdfLaTeX with TikZ, geometry, fancyhdr, AMS packages and Latin Modern (standard TeX Live). No network or external Python package is needed. The builder runs finite checks and two LaTeX passes, fixes output metadata and rejects overfull content. Clean extracted ZIP outputs must match the references byte for byte.

Print US Letter at Actual Size. Material boards have 30 mm cells; number/mask pieces and the ring are 26 mm. Three gray pieces suffice for all supplied masks; eight loose dark pieces include spares. Initially outside cells are printed on the inserts. Keep unchanged catalog cards for resets; save one final labeled-board sketch before trying another order. Tabletop sorting does not require fitting cards inside a worksheet outline. Print only the guide's selected first route, then reuse the kit.

The general ordinary jeu-de-taquin rectification theorem is attributed background. Complete finite catalogs prove only their stated finite families; local order/label/termination and inverse arguments have separate explanations. Different labels on the same shape are different outputs. Physical cutting, fit, ring/mask operation, resets and timing remain untested; no classroom pilot or Drive upload is claimed. See `SOURCES.md` and `QA.md` for provenance and release evidence.
