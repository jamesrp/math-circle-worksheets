The actual shared Grades K–5 four-page `draft/bonus.pdf` checks out mathematically. PROMPT.md and CRITIC-MATH.md were read; all four rendered pages, all six tasks, and both convention visuals were inspected. `independent-check.py` independently counts grid edges, flood-fills holes, counts local vertex occupancies, and enumerates exposed voxel faces. It imports no writer checker/data. Exact results are in `checks.json`. No located mathematical error.

- Page 1, Problem 1 asks for the shortest shared fence in a side-connected 8/8 partition of the 4×4 square. Exhaustive checking of all 12,870 balanced colorings, including the both-connected subset, gives minimum 4. Exactly four labeled partitions attain it: the middle horizontal or vertical split, in either color orientation. Both room perimeters then equal 12. The two rendered mats each have 16 equal square cells, source scale 20 mm per cell. The requirement that each room join through tile sides is compatible with every optimum.
- Page 1, Problem 2 asks for the relation among the room perimeters, interface and exterior. The exact identity is `P_R+P_B=16+2L`. Every one of the 65,536 binary colorings satisfies it, including unequal-area and disconnected cases. Exterior edges are counted once and shared edges twice. The ordinary two-room reading, inherited from P1, is a valid narrower domain; it does not need balance.
- Page 2, Problem 3 asks for corner/hole counts and a connecting rule. The actual printed shapes have `(C,R,h)` equal to `(4,0,0)`, `(5,1,0)`, `(4,4,1)`, `(4,8,2)`. Shape 2 is the ordinary five-square L: five outward corners and one inward corner, **not** `(6,2)`. The writer's corrected answer notes agree with the drawing; an earlier outline value must not enter a guide. All four drawings are side-connected and have no vertex occupied by exactly two diagonally opposite cells. Under that restriction, `C−R=4(1−h)`: with tiles on the left, the exterior loop contributes net four left quarter-turns, each hole loop net four right quarter-turns. Counts are evidence for the rule; the turning argument explains it. The shared rule and crossed-out local 2×2 diagonal pattern must retain this **local** no-pinch restriction. Global side-connectivity alone would not suffice. The outward and inward worked corner visuals correctly mark one-occupied and three-occupied vertices.
- Page 3, worked cube visual converts a two-square footprint at two layers to four cubes, correctly drawn as a 2×1×2 building. It does not reveal a target surface enumeration.
- Page 3, Problem 4 asks which of three eight-cube buildings has least exposed surface, including the bottom. All printed footprint areas and layer labels yield eight cubes; the question does not assert an unverified global optimum among arbitrary sculptures.
- Page 3, Problem 5 asks for a constant-height rule that includes footprints with holes. For `m` footprint squares, positive integer layer count `h`, and footprint perimeter `P` including all hole boundaries, `S=2m+hP`. The top and bottom each contribute `m`, and each exposed footprint edge supports `h` side faces. Independently verified by explicit voxel sets for all 511 nonempty footprints in a 3×3 box at heights 1,2,3 (1,533 checks). The printed solid-stack/covered-touching-face convention is sufficient. No overhang or zero-height interpretation was used.
- Page 4, Problem 6 asks for extrema over all arrangements of heights 1,2,3,4 on the fixed 2×2 footprint. All 24 labeled permutations were checked. Sixteen yield 34 faces, eight yield 36; no intermediate values occur. One minimum is `1 2 / 3 4`; one maximum is `1 3 / 4 2`. Every arrangement has eight top/bottom faces plus twenty exterior side faces; internal exposed faces are the absolute differences around the four-cycle. Each of the two cycle paths from height 1 to height 4 contributes variation at least three, establishing the minimum. The complete 24-case list certifies the maximum. Six blank 2×2 recording boards match the stated footprint.
