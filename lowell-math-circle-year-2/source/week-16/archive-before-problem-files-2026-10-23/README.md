# Archived base source: before the problem-file conversion, October 23, 2026

`generate.py` is the old student generator. It wrote the three band LaTeX files. The student pages are now stored as problem files one directory above (`week.toml`, `template.tex`, `figures.py`, `problems/`); `figures.py` carries its drawing code unchanged, and `editable/src/regenerate.py` writes the LaTeX from the problem files.

`three-color-triangles-week16-editable-source.zip` is the complete portable package it replaced: the October 4 fresh-review release. Neither file is current. The return-visit companion is separate.
