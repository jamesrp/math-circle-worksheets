# Week 40 bonus editable source

Standalone Python 3 source; ReportLab is the only authoring dependency. Install with `python3 -m pip install -r requirements.txt`. From this directory run `sh build.sh /absolute/output/directory`. The output directory receives `bonus.pdf`; the script does not touch repository files. `verify.py` uses only Python standard library and checks all finite examples and exact enumerations claimed in the adult notes. Sources and outputs are unpiloted; exact-material handling and physical pretests remain unperformed.

Strand rendering collects pieces and merges true endpoints before drawing each whole gap-to-gap arc, preserving continuous white channels through overpasses and closures. Build-time assertions check the expected rendered arc partition. Exact physical pencil fit remains untested.
