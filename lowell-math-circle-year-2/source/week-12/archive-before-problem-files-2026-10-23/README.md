# Archived base source: before the problem-file conversion, October 23, 2026

`make_packets.py` is the old student builder. It wrote the three band LaTeX files and ran the mathematical checks behind them. The student pages are now stored as problem files one directory above (`week.toml`, `figures.py`, `problems/`); `editable/src/regenerate.py` writes the LaTeX from them and `editable/src/check_catalan.py` carries over the checks unchanged.

`catalan-bijections-week12-editable-source.zip` is the complete portable package it replaced: the October 4 fresh-review release with the October 23 guide corrections. Neither file is current. The return-visit companion is separate.
