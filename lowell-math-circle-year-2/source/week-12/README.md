# Catalan bijections: Week 12 editable release — current editable source

**Problem files, October 23, 2026.** The student packets are stored as [problem files](../problem-files/README.md): `week.toml`, `figures.py` (the old builder's drawing code and page template) and one file per problem in `problems/`, with each band's wording inside it. The rules and worked examples are setup files: one shared by the three bands on page 1, and the path code (Grades 2–3) and walk code (Grades 4–5) on page 2, so a return-visit packet keeps them. The conversion changed no wording or figure. The three print PDFs rebuild with the same pages, extracted text and 100-dpi pixels, and the rebuilt LaTeX matches the old builder's byte for byte except one line: the Grades 2–3 rules keep the old 15 pt line spacing with a `\fontsize` command at the start of their text and `\par` at the end. compare.py's 100-dpi check snaps text to whole pixels and missed a half-point line shift here, so the rebuilt pages were also compared as exact RGB renders (pymupdf): all 18 are identical. The previous builder (`make_packets.py`) and the ZIP it replaced are in [archive-before-problem-files-2026-10-23/](archive-before-problem-files-2026-10-23/README.md).
