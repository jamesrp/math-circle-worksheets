# Week 21 shared encore student pages

Build with `bash build.sh [output-directory]`; set `PDFLATEX=/path/to/pdflatex` if needed. Requires TikZ. PDF and TeX intermediates default to `..`. No project files are required.

Print US Letter at 100%. Every working route board is 160×160 mm with equal 20 mm grid spacing. Dot centers define endpoints; ideal lines/windows/rectangle boundaries define legal locations. Use non-stretch string, tracing paper and a flat paper obstacle. The small unfold convention is illustrative. Folding registration and string handling have not been physically rehearsed; this revised student packet is unpiloted.
