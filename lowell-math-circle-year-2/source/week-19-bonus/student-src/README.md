# Week 19 shared encore student pages

Build with `bash build.sh [output-directory]`. Requires a TeX distribution with TikZ. Use `PDFLATEX=/path/to/pdflatex` if needed. The PDF and TeX intermediates go to the specified directory (default `..`). No project files are required.

Print US Letter at 100%. These are pencil selection records; use the separate complete subset-card decks for handling. This revised student packet is unpiloted.
