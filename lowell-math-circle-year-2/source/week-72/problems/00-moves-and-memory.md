## text
Move one grid edge per card: E $\rightarrow$, W $\leftarrow$, N $\uparrow$, S $\downarrow$.
For N, add the column number to the memory. For S, subtract it.
E and W leave the memory unchanged.

One partner moves the robot; the other changes its memory marker and checks each move. Use the loose memory strip from page 5 for every problem. Keep the cards in order, or write a longer route as letters. Each trial starts at the marked dot with memory 0.
