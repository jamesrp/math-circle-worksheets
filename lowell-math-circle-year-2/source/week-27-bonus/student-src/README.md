# Week 27 encore student source
Run `python3 build.py [output-directory]` with pdflatex on PATH, or set `PDFLATEX=/path/to/pdflatex`. Output is `bonus.pdf` and build intermediates are under the chosen directory (default `..`). Standard packages: geometry, TikZ, array, fancyhdr, lmodern. No project files or absolute paths are required.
