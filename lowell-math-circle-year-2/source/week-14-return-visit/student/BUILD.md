# Week 14 return-visit revised student draft

This is a self-contained LaTeX source. No external figures or repository files
are needed. It requires a standard TeX installation with TikZ and Latin Modern.

From this directory, run twice:

```sh
pdflatex -interaction=nonstopmode -halt-on-error return-visit.tex
pdflatex -interaction=nonstopmode -halt-on-error return-visit.tex
```

The result is `return-visit.pdf`, six US Letter pages. Print single-sided at
100 percent. Main polygon circumdiameters are four inches. Smaller polygons
are convention examples or copies for saving configurations.

Page map:

- Pages 1–2, Problem 1, Grades K–1: ear peeling, with a pentagon convention
  example, two hexagon triangulations, and records of removal routes.
- Pages 3–4, Problem 2, Grades 2–3: three-color corner labels and minimum
  corner covers on the fan and central-triangle hexagon drawings.
- Pages 5–6, Problem 3, Grades 4–5: half-turn, one-third-turn and one-sixth-turn
  symmetric hexagon triangulations, with a rotation convention example and
  copies for saving the drawings.

This is a revised review draft. The fresh independent critic and mathematical
reviews found no mathematical defect. The revision explicitly locates the second
large drawing in Problems 1 and 2. Physical tracing/erasure procedures and classroom
use remain untested; this packet is unpiloted.
