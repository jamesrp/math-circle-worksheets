## prompt @17.4
Use A, B, C and D again. Make one pair that matches and one pair that you think cannot match.

## key
A matching pair can use identical labelings, with one model subsequently rotated. An unmatching pair is the four-label mirror pair from Problem 2. Check all corners, including the back.
