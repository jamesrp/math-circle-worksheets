# Portable Week 46 bonus sources

Requires Python 3.10+ and ReportLab 4+. Install with `python3 -m pip install reportlab`.
Run `python3 build.py --out /absolute/scratch/output` to create `bonus.pdf` there.
Run `python3 verify.py` for the independent finite checks. No repository imports, fonts, or assets are needed.
Print Letter, single-sided, Actual Size. The large counter circles have diameter 62 points (21.9 mm); small diagrams are examples.
Unpiloted. Digital rendering does not test physical counter fit or handling.
