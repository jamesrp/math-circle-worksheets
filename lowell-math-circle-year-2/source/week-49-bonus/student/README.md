# Portable Week 49 bonus sources

Requires Python 3.10+ and ReportLab 4+. Install with `python3 -m pip install reportlab`.
Run `python3 build.py --out /absolute/scratch/output` to create `bonus.pdf`.
Run `python3 verify.py` for independent mathematical checks. No repository imports, fonts or assets are needed.
Print Letter, single-sided, Actual Size. Small examples and recording diagrams are not working mats.
Unpiloted; exact fit, cutting and handling remain physically untested.
