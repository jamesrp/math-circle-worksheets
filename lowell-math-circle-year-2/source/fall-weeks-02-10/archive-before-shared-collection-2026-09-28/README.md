Print **US Letter, single-sided, at 100% / Actual Size**. Give one student page at a time. Keep the facilitator solutions separate. For the present roster, prepare starting pages for three K–1 children, four middle children, and three upper children. Use each weekly README for the starting-page recommendation; keep later pages and the extra as continuation masters, copying only when needed. Select and print likely continuation pages before the meeting. Other masters can be shown as prompts with scrap paper for records; this plan does not require a printer in the room. Retain any earlier mat needed by a later problem. Do not hand every page to every child at the start.

The extra is an optional next investigation and may span several pages. Its grade label indicates reasoning demands, not an age gate. Offer it when the child is ready and an adult can help launch it. The full packet is not a completion target for the hour.

## Editable sources and rebuilding

Each `lowell-math-circle-year-2/source/week-NN/` folder contains the LaTeX sources, its style file, build script, README, and review record. All diagrams are code-native vector drawings, sharp at print resolution. Mathematical verification scripts are linked in the weekly READMEs.

To rebuild one week, run `sh lowell-math-circle-year-2/source/week-02/build.sh` from the repository root, changing the week number as needed. To rebuild all nine and the consolidated sets, run `sh lowell-math-circle-year-2/source/fall-weeks-02-10/build.sh`.

Building requires pdfLaTeX with TikZ and Source Sans Pro (as for Week 1), plus Python 3. The assembler uses `pypdf`, `pdfplumber`, and `reportlab`; the build script selects the Codex bundled Python on this computer when available. Contents pages embed Arial (macOS) or DejaVu Sans (Linux). Rendering uses Poppler's `pdftoppm`. The [assembler](assemble.py) also checks page dimensions, nonempty text, safe text bounds, and that each student page contains a numbered problem without obsolete worksheet labels; rerender after changing layout.

The separate [independent mathematical checks](independent-checks.py) verify finite models for cycle toggles, permutation orders, ring orbits, shuffles, optimal binary queries, subtraction games, Nim, Wythoff pairs, and billiard endpoints. These checks supplement the proofs. See the [overall review](REVIEW.md) for validation scope and the fixes found in review.
