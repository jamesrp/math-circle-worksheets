Print **US Letter, single-sided, at 100% / Actual Size**. Give one student page at a time. Keep the facilitator solutions separate. For the present roster, prepare ten starting pages. Week 2 starts everyone on shared page 1; later pages are chosen by interest and readiness, with one adult anchored to each table. Use each weekly README for the starting-page recommendation; keep later pages and the extra as continuation masters, copying only when needed. Select and print likely continuation pages before the meeting. Other masters can be shown as prompts with scrap paper for records; this plan does not require a printer in the room. Retain any earlier mat needed by a later problem. Do not hand every page to every child at the start.

In Weeks 3–10, the extra is an optional next investigation and may span several pages. Its grade label indicates reasoning demands, not an age gate. Offer it when the child is ready and an adult can help launch it. The full packet is not a completion target for the hour.

Weeks 4–10 retain **0–10 materials, 10–15 launch, 15–35 investigation, 35–40 movement/reset, 40–55 continuation, 55–60 share/tidy**; Week 3 uses a shorter common launch and two long investigations (see its guide), and Week 2 uses its revised September 28 schedule, with a satisfying stopping point and optional proof for each group. The [shared divisibility scaffold](../../../plans/coprime-divisibility-scaffold.md) gives adult support for Weeks 4 and 9. Record actual mathematical experiences using *tried / conjectured / verified these cases / proved / given as a theorem* in the use log.

The added pages provide larger work areas and contrasting examples before changing representations. They do not enlarge the hour or create a completion requirement. ## Editable sources and rebuilding

Each `lowell-math-circle-year-2/source/week-NN/` folder contains the LaTeX sources, its style file, build script, README, and review record. All diagrams are code-native vector drawings, sharp at print resolution. Mathematical verification scripts are linked in the weekly READMEs.

To rebuild one week, run `sh lowell-math-circle-year-2/source/week-02/build.sh` from the repository root, changing the week number as needed. To rebuild all nine and the consolidated sets, run `sh lowell-math-circle-year-2/source/fall-weeks-02-10/build.sh`.

Building requires pdfLaTeX with TikZ and Source Sans Pro (as for Week 1), plus Python 3. The assembler uses `pypdf`, `pdfplumber`, and `reportlab`; the build script selects the Codex bundled Python on this computer when available. Contents pages embed Arial (macOS) or DejaVu Sans (Linux). Rendering uses Poppler's `pdftoppm`. The [assembler](assemble.py) also checks page dimensions, nonempty text, safe text bounds, and that each student page contains a numbered problem without obsolete worksheet labels; rerender after changing layout.

The separate [independent mathematical checks](independent-checks.py) verify finite models for cycle toggles, permutation orders, ring orbits, shuffles, optimal binary queries, subtraction games, Nim, Wythoff pairs, and billiard endpoints. These checks supplement the proofs. See the [overall review](REVIEW.md) for validation scope and the fixes found in review.

For a one-week update, run `refresh-week.py --week 3` with the bundled Python. It reads the existing combined PDFs and `tmp/pdfs/fall-weeks-02-10/manifest.json`, replaces the selected week, regenerates contents and bookmarks, and verifies that all other page text and content streams remain identical. It does not read archived weekly PDFs.
