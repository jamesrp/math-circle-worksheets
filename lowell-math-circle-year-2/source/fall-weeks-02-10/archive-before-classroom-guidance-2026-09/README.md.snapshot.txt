Print **US Letter, single-sided, at 100% / Actual Size**. Give one student page at a time. Keep the facilitator solutions separate. For the present roster, print three K–1 copies, three middle copies, and one upper copy of the chosen week; keep one extra page in reserve. Do not hand every page to every child at the start.

The extra is an optional next investigation. Its grade label indicates reasoning demands, not an age gate. Offer it when the child is ready and an adult can help launch it. The full packet is not a completion target for the hour.

All facilitator guides use **0–10 materials, 10–15 launch, 15–35 investigation, 35–40 movement/reset, 40–55 continuation, 55–60 share/tidy**, with a satisfying stopping point and optional proof for each group. The [shared divisibility scaffold](../../../plans/coprime-divisibility-scaffold.md) gives adult support for Weeks 4 and 9. Record actual mathematical experiences using *tried / conjectured / verified these cases / proved / given as a theorem* in the use log.

## Planning and reuse

The [mathematical redesign rationale](../../../plans/fall-weeks-02-10-mathematical-redesign.md) explains the changed activities and mathematical progression. Each weekly plan records prerequisites, materials, launch, timing, exploration prompts, hints, extensions, facilitator reasoning, precise source references, and prior-use notes. The [fall plan](../../../plans/fall-k-5-year-a.md) retains the seven-child/two-adult arrangements and the [source notes](../../../plans/lesson-format-source-notes.md) distinguish book evidence from our proposals.

Record only the actual instances used in the [session log](../../../plans/fall-k-5-year-a-use-log.md), including any extra page. The earlier proposals are preserved in [the archive](../../../plans/archive-pre-depth/fall-k-5-year-a-activities.md). This is one enriched fall sequence, not a complete six-year curriculum; unused investigations remain available for returners.

## Editable sources and rebuilding

Each `lowell-math-circle-year-2/source/week-NN/` folder contains the LaTeX sources, its style file, build script, README, and review record. All diagrams are code-native vector drawings, sharp at print resolution. Mathematical verification scripts are linked in the weekly READMEs.

To rebuild one week, run `sh lowell-math-circle-year-2/source/week-02/build.sh` from the repository root, changing the week number as needed. To rebuild all nine and the consolidated sets, run `sh lowell-math-circle-year-2/source/fall-weeks-02-10/build.sh`.

Building requires pdfLaTeX with TikZ and Source Sans Pro (as for Week 1), plus Python 3. The assembler uses `pypdf`, `pdfplumber`, and `reportlab`; the build script selects the Codex bundled Python on this computer when available. Contents pages embed Arial (macOS) or DejaVu Sans (Linux). Rendering uses Poppler's `pdftoppm`. The [assembler](assemble.py) also checks page dimensions, nonempty text, safe text bounds, and that every extra is exactly one page; rerender after changing layout.

The separate [independent mathematical checks](independent-checks.py) verify finite models for cycle toggles, permutation orders, ring orbits, shuffles, optimal binary queries, subtraction games, Nim, Wythoff pairs, and billiard endpoints. These checks supplement the proofs. See the [overall review](REVIEW.md) for validation scope and the fixes found in review.
