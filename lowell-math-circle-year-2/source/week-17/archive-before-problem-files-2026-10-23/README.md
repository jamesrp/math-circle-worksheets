# Archived base source: before the problem-file conversion, October 23, 2026

`build_packets.py` is the old student builder. It wrote the three band LaTeX files. The student pages are now stored as problem files one directory above (`week.toml`, `figures.py`, `problems/`); `figures.py` carries its drawing code and page template, and `editable/src/regenerate.py` writes the LaTeX from the problem files. `editable/src/check_math.py` still checks the machines.

`finite-state-memory-week17-editable-source.zip` is the complete portable package it replaced: the October 4 fresh-review release. Neither file is current. The return-visit companion is separate.
