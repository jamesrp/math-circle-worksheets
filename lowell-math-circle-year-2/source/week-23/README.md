The previous builder and the ZIP it replaced are in [archive-before-problem-files-2026-10-23/](archive-before-problem-files-2026-10-23/README.md).

**October 23, 2026: printable table kit.** The review card's must-fix asked for the mat, cards and bars the guide specifies. The guide's preparation section names the kit and counts cutting time; the student packets did not change. The previous guide PDF and the previous ZIP are in `archive-before-card-fixes-2026-10-23/` in the print and source folders. The kit is physically unrehearsed.

Read `editable/README.md` for that package's dependencies, edit points, and rebuild commands. Its internal relative paths are preserved.
