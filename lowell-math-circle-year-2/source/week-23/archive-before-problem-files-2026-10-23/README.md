# Archived base source: before the problem-file conversion, October 23, 2026

`build_packets.py` is the old student builder. It wrote the three band LaTeX files and then checked every printed machine by exhaustion. The student pages are now stored as problem files one directory above (`week.toml`, `figures.py`, `problems/`); `editable/src/regenerate.py` writes the LaTeX from them and `editable/src/check_networks.py` carries over the checks unchanged.

`sorting-networks-week23-editable-source.zip` is the complete portable package it replaced: the October 3 release with the October 23 table kit. None of these files is current. The bonus companion is separate.
