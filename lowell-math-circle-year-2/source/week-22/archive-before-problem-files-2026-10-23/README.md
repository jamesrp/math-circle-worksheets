# Archived base source: before the problem-file conversion, October 23, 2026

`build_packets.py` is the old student builder, and `examples.py` held its opening region key. Together they wrote the three band LaTeX files. The student pages are now stored as problem files one directory above (`week.toml`, `template.tex`, `figures.py`, `problems/`); `figures.py` carries the board, recording-board and region-key code unchanged, `editable/src/regenerate.py` writes the LaTeX from the problem files, and `editable/src/check_examples.py` and `check_geometry.py` still check the key and the answers.

`four-point-convex-partitions-week22-editable-source.zip` is the complete portable package it replaced: the October 4, 2026 fresh-review release with the introduction-audit follow-up. Neither file is current. Bonus companions are separate.
