## prompt
Build nine towers on the first grid with your 18 cubes, one tower on each square, so that every row and every column has one tower of each height 1, 2, and 3. Towers placed like this make a city. In the boxes around the grid, write how many towers you see from each end of every row and every column, and write the heights in the grid. Then build a different city on the second grid and do the same.
