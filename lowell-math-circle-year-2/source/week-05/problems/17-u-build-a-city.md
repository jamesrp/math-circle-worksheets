## prompt
Build sixteen towers on this grid with your 40 cubes, one tower on each square, so that every row and every column has one tower of each height 1, 2, 3, and 4. Towers placed like this make a city. In the boxes around the grid, write how many towers you see from each end of every row and every column, and write the heights in the grid.
