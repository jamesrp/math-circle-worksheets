# Archived base source: before the problem-file conversion, October 23, 2026

`build_packets.py` is the old student builder. It wrote the three band LaTeX files and checked the printed shapes and the small-tile answers. The student pages are now stored as problem files one directory above (`week.toml`, `figures.py`, `problems/`); `editable/src/regenerate.py` writes the LaTeX from them and `editable/src/check_shapes.py` carries over the checks unchanged.

`polyomino-perimeter-week26-editable-source.zip` is the complete portable package it replaced: the October 4 fresh-review release with the October 23 guide corrections. Neither file is current. Bonus companions are separate.
