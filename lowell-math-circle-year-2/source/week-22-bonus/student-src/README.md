# Week 22 shared encore student pages

Build with `bash build.sh [output-directory]`; set `PDFLATEX=/path/to/pdflatex` if needed. Requires TikZ. PDF and TeX intermediates default to `..`. No project files are required.

Print US Letter at 100%. All main working regions use equal 16.25 mm axis units and an eight-unit square (130×130 mm). Use tracing copies and markers; dot centers are ideal locations. Boundary points count in a region. Physical tracing/marker alignment is untested; this revised student packet is unpiloted.
