Week 20: Can an averaging landscape hide a peak?

Library slot, not a scheduled meeting. Rebuild of atlas lead GA-05, unpiloted. The elementary destination is a local-to-global theorem, not an equation-solving drill or a preview of calculus. Choose a fresh problem sequence; the checked arrangements and proof below are writer/adult knowledge rather than instructions to print for children.

Mathematical kernels

1. The finite maximum principle. Work on a finite undirected graph with no loops or repeated edges. Some vertices are fixed; every connected component contains at least one fixed vertex. At each unfixed vertex, its value must equal the arithmetic mean of the values at its neighboring vertices, all at the same time. Every value lies between the smallest and largest fixed values in its component. To prove the upper bound, suppose a value exceeds all fixed values and take a vertex of greatest value M. It is unfixed. An average of numbers no larger than M equals M only if they all equal M. Thus every neighbor has value M. Follow a path toward a fixed vertex, repeating the argument at each unfixed vertex until reaching the first fixed one: it would also have value M, a contradiction. Apply the same reasoning to a minimum for the lower bound. The condition about fixed vertices matters: with no fixed vertex on a connected component, every constant value is a solution, so there is no boundary bound. Equal-valued neighboring vertices are allowed; the theorem does not say every interior value is strictly between the global boundary extremes.

2. Uniqueness without an equation-solving algorithm. If two assignments satisfy the same fixed values and averaging rule, their pointwise difference still averages its neighbors and is zero on fixed vertices. The maximum and minimum principles force this difference to be zero everywhere. Thus there is at most one assignment. Existence is a separate question, not a consequence of uniqueness; the concrete examples here establish it by displaying an assignment. Checked whole-number instances: on the path 0—u—v—12, the unique interior values are u=4, v=8. On a three-leaf star with fixed leaf values 0, 6, 12, the central value is 6. On the five-vertex tree with fixed A=0, B=12, C=9 and edges A–u, C–u, u–v, v–B, the values are u=6 and v=9: (0+9+9)/3=6 and (6+12)/2=9. These show the same local rule on different degrees and do not require a formula for a whole network. A path with fixed ends 0 and 1 and one interior vertex instead requires 1/2; limiting the available number cards to integers changes existence, so avoid accidental impossible integer-only tasks. Iterative adjustment is a way to experiment, not a proof of exact convergence or a license to check different vertices at different moments.

Suggested emphasis by level

- K–1: compare small stacks and make equal-sharing arrangements on tiny graphs; adult-supplied rules, small counts, and simple visual equality are sufficient.
- Grades 2–3: build several simultaneous whole-number landscapes and investigate whether a hidden peak is possible; add small collections and divide evenly by two or three.
- Grades 4–5: turn the local averaging restriction into a global impossibility proof; uniqueness is a deeper continuation for children ready to compare signed differences.

Materials

For each of three tables: 80 counters or connecting cubes, six small number/stack mats, a dozen blank number cards, eight short strips for graph edges, blank paper, pencils, and a small whiteboard. Use fixed vertices with an unmistakable square border or lock icon and movable vertices with round borders; color is optional, never the sole distinction. Graph nodes must be at least 3 cm across if actual stacks stand on them. Mark edge crossings that are not vertices clearly. Fixed vertices are exempt from averaging. Values are independent amounts, not a conserved pile to move around the graph; use spare counters or drawn copies when checking an average so the reference arrangement is not silently changed. The writer should select low-valued whole-number examples for the younger groups; if a task genuinely needs fractions, supply the representation and gate it accordingly. Do not imply integer-only choices unless that is intentionally the question. Paper folding, graph paper, rulers, calculators, and computers are unnecessary.
