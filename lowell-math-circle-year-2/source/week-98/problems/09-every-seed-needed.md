## prompt [2-3]
Grow the four-seed start. Then test all four ways to leave out one seed and start again. Is every seed needed? Is four the fewest seeds that can fill the board?

## prompt [4-5]
Grow this start, then test all four ways to leave out one seed and start again. Is every seed needed? Is four the smallest number of seeds that can fill the board? Find a different four-seed start that fills the whole board and still needs every seed.
