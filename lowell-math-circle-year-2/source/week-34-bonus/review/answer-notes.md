## Precise answers

Convention for keys: indices0..n−1 clockwise from the top in the shown reference; this is a description of the reference, not a permanent home mark on working mats. Rotations map i to i+r modulo n. Reflections map i to k−i modulo n. Counter-kind names never swap. Whole turn is identity and is excluded from the requested nonidentity-motion counts. Outline-square icon orientation carries no information: only its presence at a spot counts. Layer identities remain fixed.

Problem 1: One matching flip: AABBBB (110000), only k=1. Two matching flips: ABBABB (100100), k=0,3. Three matching flips: ABABAB (101010), k=0,2,4. Other rotated/flipped witnesses accepted. The six possible reflection alignments are three axes through opposite vertices and three through opposite edge midpoints. The original pattern stays fixed while a tracing copy tests these alignments.

Problem 2: Impossible. Matching rotations form a subgroup of the six cyclic rotations. If the least positive matching rotation is d (set d=6 if none nonidentity), then d divides6 and there are6/d matching rotations. If any reflection matches, composing it with each matching rotation gives exactly the matching reflections; composing two matching reflections gives a matching rotation. Thus positive matching-flip counts can only be divisors of6:1,2,3,6. Zero is also possible for some binary six-rings, e.g AABABB. Experimental inability to make4 is evidence; the composition argument supplies the general explanation. No group vocabulary is required from children.

Problem 3: Starting word AAABBABB, positions 0,1,2,5 are A. Half-turn pairs are(0,4),(1,5),(2,6),(3,7). The first and third pairs mismatch; the other two already match. At least one counter in each mismatched pair must change, so minimum 2. Four best repairs arise by making each of(0,4),(2,6) all A or all B independently. Two examples: all A choices give A at{0,1,2,4,5,6}, word AAABAAAB; all B choices give A at{1,5}, word BABBBABB. Both cost 2 from the starting pattern. The other two A-position sets are{0,1,4,5} (AABBAABB) and{1,2,5,6} (BAABBAAB). Adult can accept any two of the four.

Problem 4: Vertical flip through top and bottom spots is k=0: fixed spots0,4 and pairs(1,7),(2,6),(3,5). All three pairs mismatch, so minimum 3; eight minimum repairs choose one kind for each pair, fixed spots unchanged. One-spot turn has one cycle of all eight positions: either all A or all B, cost 4. Two-spot turn has two cycles{0,2,4,6} and{1,3,5,7}. Each contains two As and two Bs, so each costs2, total 4; four minima independently choose one kind for each parity cycle. Thus the selected flip takes fewest changes(3 versus4,4). For a general fixed motion, each cycle must be monochromatic; cost per cycle is its length minus its largest same-kind frequency. Motion stays fixed during optimization. The shared working mat from Problem 3 may be reused, with the printed original retained and each recorded final repair available to compare.

Worked layer visual: Four-position first layer has filled marks{0,1}; second has outline marks{1,3}. Stack remembers each ordered pair: spot0 filled only,1 both,2 neither,3 outline only. Shapes are positioned separately within a spot so the overlap preserves both identities. This is a non-task example.

Problem 5: First layer has a unique filled mark at0; second has a unique outline mark at1. Each layer has exactly one matching reflection(k=0 and k=2 respectively), and only the identity rotation. Their intersection contains only identity, so stack loses every nonidentity motion. Both individual reflections exist but are different. Adjacent marked positions are one witness; more complex patterns can also work. Unique marks at opposite spots0 and3 would instead retain the common k=0 reflection and are not a solution. Layers must stay distinct; an uncolored union of marks would have a different symmetry set.

Problem 6: Impossible for a stack to lose their common half-turn. At every spot, each layer's mark/blank status agrees with the opposite spot; the ordered pair therefore agrees too. Concrete examples: first marks{0,3}, second marks{1,4}; their stack still matches a half-turn. In general, the stack's matching-motion set equals the intersection of the two layer sets. A motion matching both cannot disappear, and any stack match must match both components. This explains the difference between Problem 5's distinct reflections and Problem 6's common motion.
