## Recommended wording/representation changes

1. **Distinguish the sample estimate from the exact result in Problem 1's route.** The twelve walks produce an observed average; they cannot establish the exact expected path scores. The question already asks for an exact result, so it does not explicitly make a false claim, but the adult route must supply a reason beyond the sample and identify what remains conjectural. A brief “use the walks to estimate” wording would make that distinction clearer. Keep the exact first-step/averaging explanation available as later work rather than making adults calculate it for a child to finish the first page.

2. **Make “exactly two ticks” mean first return in Problem 2.** A constant board also returns after two ticks because it returns after one. “First returns after two ticks” removes that harmless but distracting ambiguity and preserves the intended nonconstant two-cycle search.

3. **Provide a recoverable BEFORE/AFTER pair for Problems 3–4 as promised in preparation.** Only one two-circle diagram and a value table are printed on page 3, while the unchanged-reference rule requires two states. Reuse the separate table mats or provide a second copy; do not have children overwrite the source board one circle at a time. This can be handled by the adult preparation without more student directions.
