# Week 20 final answers and assumptions

Three directions: fair stopping walks (1), repeated whole-board dynamics (2–4), least-rough landscapes (5–6). Grades 2–5 is approximate: adult reading and fair-choice support are needed; fractions and explaining a never-exact limit gate Problem 4. Squared areas can replace multiplication in 5–6. Physical fair drawing, simultaneous updates and cube fit have not been rehearsed. These tasks do not repeat static mean-board filling or base peak/uniqueness proofs.

1. Expected score A=2, B=4, C=3. Sample averages need not equal these values and are experimental estimates. On the path let expected values be a,b: a=b/2, b=(a+6)/2, hence a=2,b=4. Each walk stops almost surely: from each circle there is a path to a square of bounded length with a positive probability of following it; repeated blocks bound survival geometrically. Center C has three equally likely immediate terminal scores 0,3,6, mean3. Zero counts as a full participant. The record asks only terminal scores, never concurrent step counts or means.
2. Four-cycle clockwise values are 0,6,0,6 at tick0; 6,0,6,0 at tick1; then tick0 returns. Any alternating a,b,a,b with a not equal b gives a genuine period-two state, e.g. 1,5,1,5. Constant values are unchanged and have period one, not exactly two. All updates use the same old board. The non-task three-node path convention shows 0,3,6 updating to 3,3,3; endpoint circles have one neighbor and the middle uses (0+6)/2. This is a dynamic rule, distinct from checking a static filling.
3. Neighbor-only two-circle values swap 0,6 and 6,0 forever. Own-and-neighbor averaging gives 3,3 on the first tick and remains there.
4. Own-plus-two-neighbors cycle: tick1=4,2,4,2; tick2=8/3,10/3,8/3,10/3; tick3=28/9,26/9,28/9,26/9. Each value approaches3. The alternating signed deviation from3 is multiplied by -1/3 each tick, so it never becomes zero after finitely many ticks. A drawing argument can track nonzero unequal alternating values and shrinking gap. No universal convergence theorem is asserted by these examples.
5. Score is x^2+(6-x)^2. For x=0,1,2,3,4,5,6 the scores are 36,26,20,18,20,26,36. Unique whole-number minimum18 at3. It is also the real minimum because the score equals18+2(x-3)^2. Adult may use moving equal squares or completing the square. The printed convention 0—1—3 has gaps1,2, square areas1,4, total5.
6. Score x^2+(y-x)^2+(6-y)^2. Unique minimum12 at x=2,y=4, also among all real values. With three gaps summing6, equal gaps2 minimize total squares. Elementary certificate: sum of (gap_i-2)^2 equals score-12. This includes negative signed gaps for a nonmonotone choice; squaring absolute gaps gives the same score. Exhaustive integer choices0–6 verify12 is unique. General adult energy fact under fixed boundary: harmonic fillings uniquely minimize edge squared gaps when every component reaches a fixed square; no full energy proof is requested from students.

All graphs are undirected, finite, connected; each walk board reaches a fixed square. Dynamic boards deliberately have no fixed square. Roughness boards restrict guesses to whole numbers with an integral harmonic optimum. Experiments and exact explanations must be distinguished in adult use.
