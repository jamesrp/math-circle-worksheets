# Week 56-57 external references

Downloaded October 4, 2026 for the new polyhedral-surface and lattice-area research. These are reference inputs, not files to redistribute inside student source ZIPs. Exact URLs, file sizes, SHA-256 hashes and relevant sections are in [sources.json](sources.json).

- Keenan Crane, [Discrete Differential Geometry: An Applied Introduction](https://www.cs.cmu.edu/~kmcrane/Projects/DDG/): university author course notes; Euler disk/sphere exercise and discrete angle-defect/Gauss-Bonnet exercises were read and rendered.
- Vicky Neale, [Euler's Formula](https://nrich.maths.org/articles/eulers-formula): original Cambridge NRICH explanation and graph proof.
- Cambridge NRICH, [Pick's Theorem](https://nrich.maths.org/problems/picks-theorem) and [Proof of Pick's Theorem](https://nrich.maths.org/problems/proof-picks-theorem): original educational tasks and elementary additive proof.
- Thomas F. Banchoff, [The Search for Regular Polyhedra](https://www.math.brown.edu/tbanchof/Beyond3d/chapter5/section02.html): author-hosted book section about local regular-polygon fans.

The local MSRI books and first-year handouts were read in their existing locations and were not copied here. Specific source facts, independent derivations, novelty comparisons and unpiloted readiness proposals are recorded in [Week 56 notes](../../../plans/new-themes-52-63/week-56/research-notes.md) and [Week 57 notes](../../../plans/new-themes-52-63/week-57/research-notes.md).
